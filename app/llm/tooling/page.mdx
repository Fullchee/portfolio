## Principles

- Don't add a tool/complexity unless I actually have the problem it solves
- Prefer GUIs over TUIs
- Token savings must be real

## Models

### Using

- [Claude](https://claude.com/pricing): $20 USD/month, $200 USD/year
- [OpenCode](https://opencode.ai) free models
    - [OpenCode Go](https://opencode.ai/go): $10 USD/month

### Dropped

Felt slow compared to Claude and OpenCode free models

- [freellmapi: Stack LLM free tiers](https://github.com/tashfeenahmed/freellmapi)
- [turbo-fieldfare: Gemma 4 26B-A4B inference in ~2 GB of RAM on any M-series MacBook · GitHub](https://github.com/drumih/turbo-fieldfare)

## Text to speech (TTS)

Problem: I want to listen to Claude Code output. 2026 macOS built-in Siri voices are still too robotic.

### Using

- [ElevenLabs](https://elevenlabs.io/) API key (free tier) for listening to Claude output
    - Mac OS Shortcuts: global
- [Kokoro](https://github.com/remsky/Kokoro-FastAPI) for converting longer text files into audio

### Dropped

- [edge-tts](https://pypi.org/project/edge-tts/)
    - API calls to Microsoft Edge TTS, frequently fails
- 2026: [GitHub - KittenML/KittenTTS: State-of-the-art TTS model under 25MB 😻 · GitHub](https://github.com/KittenML/KittenTTS)
    - pretty good but more robotic than built-in 2026 macOS Siri voices

## Token / context savers

### Dropped

All: unproven token savings. They also conflicted with `codegraph` (would `caveman grep` / `rtk grep` instead of using it), though that's moot now that I've dropped `codegraph`.

- caveman
    - fewer output tokens, but might not save tokens overall
- [rtk](https://github.com/rtk-ai/rtk)
    - filters and compresses command outputs before they reach your LLM context
    - might not actually save tokens
- [context-mode](https://www.youtube.com/watch?v=QUHrntlfPo4)

## Terminals

### Using

- [cmux](https://cmux.com/)
    - built-in browser

### Considered

- [herdr](https://herdr.dev/): tmux for agents
    - LLM can launch and reference other instances and panes
    - when you close the terminal, you don't lose your work
    - essential if you SSH to your Mac
    - but doesn't make sense in a terminal like cmux or Warp, which already have left side panels

### Dropped

- [Warp](https://www.warp.dev/)
    - didn't really need much of its nice UX (code diff/review, code editor, their agent stuff you have to pay for)
